POS Receipt Manager

Prepare clean, configurable thermal-style receipts for Odoo 20 Community POS browser printing. Configure each POS independently without replacing Odoo's native receipt, payment, or printer flow.

What this module provides

  • Per-POS receipt layout settings for different stores or counters.
  • Standard thermal widths: 58mm, 80mm, and 112mm.
  • Custom paper width from 40mm to 210mm.
  • Independent left and right margins with validation.
  • Small, normal, and large receipt font profiles.
  • Browser print page-size hints with a measured receipt height.
  • Arabic/RTL-safe receipt direction and normal text wrapping.
  • Native Odoo printer mode remains available as a fallback.

Configuration

  1. Open Point of Sale > Configuration > Point of Sale.
  2. Open the target POS configuration.
  3. Open the Configuration tab and find POS Receipt Manager.
  4. Enable the manager, select the paper width, margins, font profile, and printing method.
  5. Reload the POS session after changing receipt settings.

Printing behavior

In browser mode, the module formats Odoo's native receipt and adds a CSS page-size hint for the configured width. The browser print dialog and operating-system printer driver remain authoritative. For reliable results, disable browser headers and footers and configure the same paper width in the printer driver.

What is intentionally not included

  • No Bluetooth communication or Android bridge.
  • No ESC/POS transport, automatic cutting, or cash-drawer commands.
  • No silent printing or printer-driver configuration.
  • No replacement of Odoo payment, tax, stock, or accounting logic.

Compatibility and quality

  • Odoo 20 Community Edition only.
  • Depends only on the standard point_of_sale module.
  • Validated with an isolated Odoo 20 installation, upgrade, and ORM test run.
  • Uninstall-safe presentation extension: native Odoo receipt behavior remains the fallback.

Important: CSS can prepare the browser output, but it cannot override a physical printer driver's paper size or printable area. Test the final result with the intended printer model.
